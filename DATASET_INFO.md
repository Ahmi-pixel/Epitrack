# Dataset Information

## HAM10000
- **Source:** Kaggle
- **Size:** 10,015 images
- **Classes:** 7 (melanoma, nevus, basal_cell_carcinoma, etc.)
- **Download:** https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000

## DermNet
- **Source:** Kaggle
- **Size:** 20,000+ images
- **Classes:** 23 disease categories
- **Structure:** Pre-split into train/test folders

## Combined Dataset (Phase 7)
- **Total:** 24 classes (removed 5 weakest)
- **Images:** ~31,000
- **Split:** 70% train, 15% val, 15% test
- **Location:** `ml/data/organized_clean_24/`
